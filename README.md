# Ezo Eylül Sağır — Interior Architecture Portfolio

A modern, responsive and interactive interior architecture portfolio designed to present architectural projects through immersive visuals, cinematic presentation and a refined dark interface.

### Live Demo

[View Live Website](https://furkan-akpinar.github.io/ezo-eylul-sagir-interactive/)

---

## Overview

This project is a multi-page interior architecture portfolio focused on visual storytelling and responsive user experience.

The website presents architectural concepts through project galleries, cinematic media and dedicated project pages while maintaining a consistent visual identity across desktop and mobile devices.

---

## Features

- Fully responsive multi-page layout
- Modern dark user interface
- Cinematic homepage presentation
- Interior architecture project galleries
- Dedicated project detail pages
- Day / night visualization comparisons
- Responsive navigation
- Mobile-friendly layouts
- Custom 404 page
- Optimized WebP image assets
- GitHub Pages deployment

---

## Selected Project Types

The portfolio includes several interior architecture concepts such as:

## Running Locally

Clone the repository:

```bash
git clone https://github.com/furkan-akpinar/ezo-eylul-sagir-interactive.git
```

Enter the project directory:

```bash
cd ezo-eylul-sagir-interactive
```

Start a local server:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```
